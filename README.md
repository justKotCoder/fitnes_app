# Подход

Личный дневник упражнений для Android. Kotlin, Jetpack Compose, чёрная тема с голубым акцентом. Работает без интернета, регистрации и подписок.

## Открыть и собрать

1. В Android Studio выберите **Open** и откройте эту папку `Setnote` (рядом лежат `settings.gradle.kts` и `gradlew`).
2. Разрешите Gradle Sync. Для первой сборки нужен интернет для загрузки зависимостей. Самому приложению интернет не нужен.
3. Используйте Gradle JDK 17 или совместимый встроенный JDK Android Studio. Установите Android SDK Platform 36 и Build Tools 35.0.0 по запросу среды.
4. Выберите подключённый Pixel 9 и нажмите Run либо соберите APK через меню Build.
5. Debug APK после сборки: `app/build/outputs/apk/debug/app-debug.apk`.

В проект включён `debug.keystore` — отладочный ключ именно этой личной версии. Он позволяет обновлять готовый APK сборками из Android Studio с сохранением записей. Сохраняйте этот файл вместе с проектом и используйте тот же `applicationId`. Ключ предназначен для отладки и личного использования.

Из терминала: `./gradlew testDebugUnitTest assembleDebug`. Если SDK не найден, задайте путь в `local.properties`: `sdk.dir=/абсолютный/путь/к/Android/sdk`.

## Как пользоваться

- Создайте программу: например, «Верх» или «Ноги».
- Добавьте упражнения, выберите учёт веса и повторов, только повторов или времени в секундах.
- При желании добавьте свою заметку и фото из галереи. Фото копируется в приватное хранилище приложения.
- Последние результаты каждого упражнения видны прямо в списке.
- «Записать подходы» раскрывает поля на месте. Новая запись начинается с одного подхода. Прошлые значения служат заготовкой: измените нужные числа и нажмите «Сохранить подходы». Добавляйте следующие через «Ещё подход» по мере выполнения.
- Клавиша «Далее» переводит к следующему числу; «Готово» в последнем поле сохраняет показанные подходы. Дробный вес можно вводить через точку или запятую.
- Позже в тот же день можно снова открыть ввод, добавить подходы и сохранить: запись обновится.
- Дату можно выбрать перед сохранением. На одну дату у упражнения предусмотрена одна запись. Это упрощает ввод, но не разделяет два занятия в один день.
- Нажмите название упражнения, чтобы увидеть фото, заметку и раскрываемую историю. Любую запись можно изменить или удалить. В истории есть кнопка «Добавить запись за другую дату», чтобы внести забытое занятие, не меняя сегодняшнюю запись.
- Порядок упражнений меняется через меню «…»: поднять / опустить.

Нет демонстрационных результатов, автоподбора нагрузки, гифок или обязательных тренировочных сессий. Сохранённые подходы находятся в локальной базе. Незавершённый ввод подходов хранится в состоянии экрана и восстанавливается при стандартном пересоздании Android; для гарантированного сохранения используйте кнопку сохранения. Удаление приложения очищает его данные. Облачное резервное копирование отключено.

## Простая Clean Architecture

Один Gradle-модуль, три слоя по пакетам:

- `domain`: модели, интерфейсы хранилищ и `SaveEntry` с проверкой введённых подходов. Не зависит от Android.
- `data`: SQLite, транзакции изменения порядка, импорт локальных фото. Реализует интерфейсы domain.
- `presentation`: Compose-экраны и ViewModel; состояние через StateFlow, зависимости передаются в конструктор.

`SetnoteApplication` и фабрика ViewModel — место сборки зависимостей. Нет Hilt, сервера, многомодульной схемы и классов use case для каждого простого CRUD-вызова. Один use case выделен там, где есть настоящие правила проверки данных.

SQLite хранит общие упражнения отдельно от их связей с программами. Удаление программы или упражнения из неё удаляет только связи; карточка и история остаются в локальной библиотеке. Для упражнения сохраняется одна запись на дату. Работа с базой и фото выполняется на IO-диспетчере; изменения сериализованы mutex. Будущие изменения схемы требуют явной миграции, сброса пользовательских данных нет.

Текущий минимум Android: 8.0 (API 26). Целевая версия: API 36. AGP 8.13.0, Gradle 8.13, Kotlin 2.2.10, Compose BOM 2025.08.00.

## Проверки перед повседневным использованием

- Создать программу, добавить упражнения всех трёх типов.
- Записать разные веса, дробный вес с запятой, повторения и секунды.
- Обновить запись за сегодня, создать запись за вчера и проверить историю.
- Изменить дату на уже занятую: приложение должно предложить открыть существующую запись.
- Свернуть и открыть приложение, повернуть экран, проверить данные после перезапуска.
- Добавить фото, удалить оригинал из галереи, проверить копию в приложении.
- Проверить ввод с клавиатурой и увеличенным системным шрифтом на Pixel 9.

## Версия 1.2 — 1 ноября 2026

- Упражнения хранятся в общей локальной библиотеке. При добавлении в программу выберите «Добавить» рядом с сохранённым упражнением или введите название нового.
- Веса, подходы, заметка, название, фотография и история общие во всех программах. Порядок упражнений у каждой программы свой.
- При вводе уже существующего названия предлагается общая карточка. Регистр букв и лишние пробелы не учитываются; способ учёта и настройка веса одной гантели должны совпадать. Похожие, но разные названия автоматически не объединяются.
- При первом запуске обновления выполняется атомарная миграция базы v1 → v2. Дубликаты объединяются. Подходы за совпадающую дату соединяются без удаления даже одинаковых подходов. Разные заметки объединяются; основное фото выбирается из карточек с более поздними тренировками.
- Точные исходные записи, заметки и пути к фотографиям остаются в служебных таблицах `legacy_programs_v1`, `legacy_exercises_v1`, `legacy_entries_v1`. Это внутренняя копия перед миграцией, а не пользовательский экспорт.
- Удаление из программы сохраняет упражнение в библиотеке. Его можно добавить снова вместе с историей. Удаление отдельной записи из истории действует во всех программах.
- versionCode: 3. Прежний ключ подписи сохранён. Устанавливайте APK поверх версии 1.0/1.1 без удаления приложения.
- Проверка: 18 JVM-тестов; SQLite-проверки схемы, сохранения исходных строк, общих результатов, независимого порядка, удаления связей и транзакционного отката. На реальном устройстве перенос пользовательской базы ещё не проверялся.
